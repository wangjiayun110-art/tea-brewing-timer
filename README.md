# Tea Brewing Timer

A free, no-sign-up tea brewing timer. Pick your tea, pick mug or gongfu brewing, and it shows the water temperature, leaf amount, and counts down each steep — with a beep when it's ready.

**Live: https://timer.calmsteep.com/** — English and Chinese, one click.

## What it does

- 6 teas: green, white, yellow, oolong, black, pu-erh
- Mug or gongfu brewing, with the right water temperature and leaf amount for each
- Countdown per steep, with next-steep support
- Mild / medium / strong strength, ±30s adjust
- Keeps running when you switch tabs (absolute timestamps, not a setInterval counter)
- English + Chinese in a single page

## Use it

Just open `index.html` in a browser — no build step, no dependencies, no backend. Or use the live site above.
